# ABOUT THE WIKI

This directory contains markdown files that have been
directly copy pasted from the GitHub wiki that Cindy created for
MFHRN. As such, it is possible that there will be out of date information
or broken links. Take everything written in this folder with a grain of
salt. 

I have tried to mirror the wiki layout as reasonably as possible while 
making it slightly easier to navigate. The main goal is for Cindy's 
documentation to live as part of the codebase rather than a seperate
thing to maintain.
